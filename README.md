# 薬学的有害事象等防止加算クイズ

GitHub Pages用の3ファイルです。

## アップロードするファイル

- `index.html`
- `style.css`
- `script.js`

3つを同じ階層に置いてください。

## 動作

1. 「開始する」
2. 全10問を1問ずつ回答
3. 回答直後に正誤と解説を表示
4. 終了後に店舗名・名前・難易度を入力
5. 「結果を送信する」
6. 既存のApps Script WebアプリへPOST
7. 送信後だけ「もう一度する」が有効

## 送信データ

```js
{
  quiz: "薬学的有害事象等防止加算クイズ",
  store: "店舗名",
  name: "名前",
  difficulty: "簡単 / ちょうどいい / 難しい",
  score: "8/10",
  answers: "2,5"
}
```

Apps Script側では `quiz` の値を見て、既存スプレッドシートの
「有害事象回答」タブへ振り分ける想定です。

※ `WEB_APP_URL` は、既存の自家製剤クイズで使用しているURLを設定済みです。


## 追加仕様

- PCの広い画面では、クイズ中に左側へ「区分・コード早見表」を固定表示します。
- 画面幅が狭い場合は、クイズ上部に折りたたみ式の早見表を表示します。
